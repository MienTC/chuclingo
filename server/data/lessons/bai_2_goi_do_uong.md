# 进阶达人：定制你的专属口味
<span class="badge">高频词汇</span> <span class="badge">摆脱千篇一律</span>

<div class="grid-3">
  <div class="card">
    <h2>📏 杯型 (大小)</h2>
    <ul>
      <li><strong>大杯</strong> (L) - 喝个够</li>
      <li><strong>中杯</strong> (M) - 刚刚好</li>
      <li><strong>小杯</strong> (S) - 尝个鲜</li>
    </ul>
  </div>
  <div class="card">
    <h2>🌡️ 温度 (冷热)</h2>
    <ul>
      <li><strong>正常冰</strong> - 标准口感</li>
      <li><strong>少冰</strong> - 微凉不上火</li>
      <li><strong>去冰</strong> - 凉的但没有冰块</li>
      <li><strong>热的</strong> - 温暖舒适</li>
    </ul>
  </div>
  <div class="card">
    <h2>🍬 甜度与加料</h2>
    <ul>
      <li><strong>正常糖 / 半糖</strong> (50%)</li>
      <li><strong>少糖 / 无糖</strong> (0%)</li>
      <li><strong>加珍珠</strong> - 经典加料</li>
      <li><strong>加椰果</strong> - 清脆口感</li>
    </ul>
  </div>
</div>

# 告别机械表达：地道点单句型
<span class="badge">摆脱“我要…”</span> <span class="badge">像本地人一样说话</span>

<div class="grid-2">
  <div class="card">
    <h2>❌ 书本句型 (太生硬)</h2>
    <ul>
      <li>我要一杯奶茶。</li>
      <li>我不要冰，不要糖。</li>
      <li>哪个好吃/好喝？</li>
      <li>我想加珍珠。</li>
      <li>我不喝这个，给我那个。</li>
    </ul>
  </div>
  <div class="card-highlight">
    <h2>✅ 地道口语 (更自然)</h2>
    <ul>
      <li><strong>来一杯</strong> 奶茶。 / <strong>麻烦帮我点一杯</strong> 奶茶。</li>
      <li>麻烦帮我做 <strong>少冰、半糖</strong> 的。 / 我要 <strong>去冰</strong> 的。</li>
      <li>你们店有什么 <strong>推荐</strong> 吗？ / 哪个卖得最好？</li>
      <li>里面可以 <strong>加</strong> 珍珠吗？</li>
      <li>这个卖完了吗？那 <strong>换成</strong> 拿铁吧。</li>
    </ul>
  </div>
</div>

# 丰富细节：为点单加上“背景理由”
<span class="badge">句子拉长</span> <span class="badge">自然交流</span>

<div class="card">
  <h2>💬 公式：状态 / 天气 + 想喝的饮品 + 定制要求</h2>
  <br>
  <p>💡 <strong>代替简单的：“我要一杯美式。”</strong></p>
  <ul>
    <li><strong>【太热了】</strong> <em>今天天气太热了，给我来一杯冰美式吧！</em></li>
    <li><strong>【太困了】</strong> <em>我昨天晚上写代码写得太晚了，今天很困，来一杯大杯咖啡。</em></li>
    <li><strong>【口味偏好】</strong> <em>我不太喜欢吃甜的，麻烦帮我做无糖的。</em></li>
  </ul>
</div>

# 社交高手：如何与同行朋友闲聊
<span class="badge">话题互动</span> <span class="badge">照顾他人感受</span>

<div class="grid-2">
  <div class="card">

      <li>你想喝点儿什么？<strong>冷还是热？</strong></li>

    <ul>
      <li>你今天能喝<strong>冰的</strong>吗？</li>

    </ul>
  </div>

    <br>
    <blockquote>这次 <strong>我买单</strong>，下次你请我吧。</blockquote>

# 场景实战一：我要定制一杯奶茶
<span class="badge">角色扮演</span> <span class="badge">场景：初次到店，询问推荐并定制</span>

<div class="card">
  <p><strong>店员 (老师)：</strong> 您好，想喝点儿什么？今天我们的果茶有打折。</p>
  <p><strong>学员：</strong> 我看一下菜单…… 你们有什么<strong>推荐</strong>吗？我不喜欢太甜的。</p>
  <p><strong>店员 (老师)：</strong> 那推荐您尝尝我们的乌龙茶，不太甜，很清爽。</p>
  <p><strong>学员：</strong> 行，那就<strong>来一杯</strong>乌龙茶。麻烦帮我做<strong>中杯、少冰、半糖</strong>。里面可以加珍珠吗？</p>
  <p><strong>店员 (老师)：</strong> 可以的，加珍珠多两块钱。一共十五块。</p>
  <p><strong>学员：</strong> 好的，我扫你二维码。</p>
</div>

# 场景实战二：卖完了怎么办？
<span class="badge">角色扮演</span> <span class="badge">场景：两人结伴买水，遇到缺货突发状况</span>

<div class="card">
  <p><strong>朋友 (老师)：</strong> 我今天有点儿累，想喝点儿甜的，你呢？</p>
  <p><strong>学员：</strong> 今天<strong>我请客</strong>吧！老板，来两杯奶茶，一大一小。</p>
  <p><strong>店员 (老师扮)：</strong> 不好意思，奶茶今天卖完了，换别的可以吗？</p>
  <p><strong>学员 (转身问朋友)：</strong> 奶茶没了，你喝果茶还是拿铁？</p>
  <p><strong>朋友 (老师)：</strong> 那我喝果茶吧，少冰的就行。</p>
  <p><strong>学员 (转回店员)：</strong> 那麻烦<strong>换成</strong>两杯果茶，一杯少冰，一杯去冰。谢谢！</p>
</div>

# 课后挑战：帮同事带咖啡
<span class="badge">语音作业</span> <span class="badge">时长限制：60秒</span>

<div class="grid-2">
  <div class="card-highlight">
    <h2>🎙️ 任务描述</h2>
    <p>假设你正在去公司的路上，经过一家咖啡馆。请给你的同事（老师）发一条语音，问问要不要帮忙带杯饮料。</p>
    <br>
    <p><strong>必须包含以下元素：</strong></p>
    <ul>
      <li>描述自己的状态 <em>（比如：太困了、太热了）</em></li>
      <li>主动提出帮忙 <em>（我正准备买水，你要不要...）</em></li>
      <li>确认对方的定制需求 <em>（冰的还是热的？甜度？）</em></li>
      <li>提到付钱 <em>（我先帮你付，回头再说...）</em></li>
    </ul>
  </div>
  <div class="card">
    <h2>🎧 参考开头</h2>
    <blockquote>“喂，你到公司了吗？我今天实在太困了，正在咖啡馆买美式。你要不要喝点什么？我顺便帮你带一杯……”</blockquote>
    <br>
    <p>⏰ <em>请在明晚 20:00 前录制并发送微信语音给老师。</em></p>
  </div>
</div>
