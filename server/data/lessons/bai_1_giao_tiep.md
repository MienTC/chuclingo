# 核心表达：姓名与家乡
<span class="badge">建立初次印象</span> <span class="badge">亲切称呼</span>

<div class="grid-2">
  <div class="card">
    <h2>🎯 常用词汇库</h2>
    <ul>
      <li><strong>外号：</strong> 朋友或同事间常用的称呼</li>
      <li><strong>称呼：</strong> 礼貌询问对方名字</li>
      <li><strong>老家：</strong> 出生成长的地方</li>
      <li><strong>呆 / 待：</strong> 在某座城市居住、生活或停留</li>
    </ul>
  </div>
  <div class="card-highlight">
    <h2>💬 核心句型与替换</h2>
    <p><strong>1. 介绍名字与昵称：</strong></p>
    <blockquote>我叫 <strong>[全名]</strong>，大家叫我 <strong>[昵称]</strong> 就行 / 就好。</blockquote>
    <p><em>例：我叫阮文安，大家叫我小安就行。</em></p>
    <p><strong>2. 介绍故乡与现居地：</strong></p>
    <blockquote>我老家在 <strong>[城市]</strong>，不过现在在 <strong>[城市]</strong> 生活 / 工作。</blockquote>
    <p><em>例：我老家在岘港，不过现在在河内，呆了两年了。</em></p>
  </div>
</div>

# 核心表达：职业与生活
<span class="badge">日常职场</span> <span class="badge">工作状态</span>

<div class="grid-2">
  <div class="card">
    <h2>🎯 常用词汇库</h2>
    <ul>
      <li><strong>做 / 搞：</strong> 口语中指“从事某个行业”</li>
      <li><strong>开发 / 程序员：</strong> 软件开发、写代码</li>
      <li><strong>设计师：</strong> 界面、视觉或空间设计</li>
      <li><strong>上班族：</strong> 朝九晚五的企业职员</li>
      <li><strong>加班：</strong> 超过正常工时工作</li>
    </ul>
  </div>
  <div class="card-highlight">
    <h2>💬 核心句型与替换</h2>
    <p><strong>1. 表达自己的职业行业：</strong></p>
    <blockquote>我是做 <strong>[岗位 / 行业]</strong> 的。</blockquote>
    <p><em>例：我是做前端开发的，平时主要写代码。</em></p>
    <p><strong>2. 描述近期工作忙闲：</strong></p>
    <blockquote>最近项目比较赶，经常需要加班。</blockquote>
    <blockquote>我是个普通的上班族，周末一般都休息。</blockquote>

# 核心表达：闲暇与兴趣爱好
<span class="badge">生活方式</span> <span class="badge">找共同话题</span>

<div class="grid-2">
  <div class="card">
    <h2>🎯 常用词汇库</h2>
    <ul>
      <li><strong>平时：</strong> 正常的非工作时段</li>
      <li><strong>没事的时候：</strong> 放松且没有特殊安排时</li>
      <li><strong>喝咖啡 / 逛街：</strong> 休闲消遣活动</li>
      <li><strong>健身 / 运动：</strong> 跑步、打球、去健身房</li>
      <li><strong>一部电影：</strong> 影像娱乐的量词搭配</li>

  </div>
  <div class="card-highlight">
    <h2>💬 核心句型与替换</h2>
    <p><strong>1. 表达日常闲暇喜好：</strong></p>
    <blockquote>平时没事的时候，我挺喜欢 <strong>[活动]</strong> 的。</blockquote>
    <p><em>例：平时没事的时候，我喜欢一个人去咖啡馆看书。</em></p>

    <blockquote>我对看电影挺感兴趣的，最喜欢科幻片。</blockquote>

# 技巧提升：地道口语过渡词
<span class="badge">争取思考时间</span> <span class="badge">拒绝尴尬停顿</span>

<div class="grid-3">
  <div class="card">
    <h2>🤔 思考停顿</h2>
    <p>脑中组织语言时使用：</p>
    <ul>
      <li><strong>那个……</strong><br><em>“那个……我想想，应该是上个月。”</em></li>
      <li><strong>怎么说呢……</strong><br><em>“这个工作，怎么说呢……挺有挑战的。”</em></li>
    </ul>
  </div>
  <div class="card">
    <h2>🔄 转换话题</h2>
    <p>自然引出新问题：</p>
    <ul>
      <li><strong>对了！</strong><br><em>“对了，你平时也经常喝咖啡吗？”</em></li>
      <li><strong>顺便问一下……</strong><br><em>“顺便问一下，你明天去公司吗？”</em></li>
    </ul>
  </div>
  <div class="card">
    <h2>💡 倾听反馈</h2>
    <p>接住对方的话题：</p>
    <ul>
      <li><strong>原来是这样！</strong><br><em>（表示恍然大悟）</em></li>
      <li><strong>可不是嘛！</strong><br><em>（表示完全赞同）</em></li>
      <li><strong>真的假的？</strong><br><em>（表示惊喜好奇）</em></li>
    </ul>
  </div>
</div>

# 随堂口语表现评估表
<span class="badge">即时反馈</span> <span class="badge">提升方向</span>

| 评估维度 | 评价标准 | 达成等级 |
| :--- | :--- | :---: |
| **反应速度** | 听到提问能否在 **3 秒** 内自然开口，无漫长卡顿 | 优秀 / 良好 / 需加强 |
| **声调饱满** | 第四声是否干脆下沉（如：`叫`、`做`、`去`）；第三声不变调错误 | 优秀 / 良好 / 需加强 |
| **地道表达** | 熟练使用 `叫我...就行`、`我是做...的`，摆脱书面僵硬表达 | 优秀 / 良好 / 需加强 |
| **拓展能力** | 拒绝单个词回答，能主动给出“回答 + 一个补充细节” | 优秀 / 良好 / 需加强 |
| **过渡连贯** | 善于使用 `那个`、`对了`、`原来是这样` 等词汇填补思考空白 | 优秀 / 良好 / 需加强 |
